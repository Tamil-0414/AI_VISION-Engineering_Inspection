# 4–5 minute demo script

## 0:00–0:30 — Problem

"This prototype explores whether a smartphone camera can perform useful engineering inspection without dedicated industrial vision hardware."

## 0:30–1:10 — Camera

Open the app and demonstrate live camera, capture and image upload.

## 1:10–2:00 — Calibration

Place a known reference beside the component. Explain:

scale = known physical length / detected pixel length.

Show the mm/px value and uncertainty.

## 2:00–3:00 — Measurement

Demonstrate the bolt, washer and bracket. Show the dimensional overlay and the engineering result.

## 3:00–3:40 — Inspection

Explain that AI is appropriate for component identification, while classical CV is better for deterministic geometry.

Show PASS/FAIL and confidence.

## 3:40–4:30 — Report

Generate the PDF and open it.

## 4:30–5:00 — Limitations

Explain that perspective, lens distortion, blur, glare and reference placement affect accuracy. State that hidden 3D geometry and critical tolerances require calibrated metrology equipment.
